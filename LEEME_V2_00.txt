MAPA OPERATIVO + TIEMPO DE GESTIÓN / SLA

IMPORTANTE
Esta versión conserva el Dashboard V1.27 y agrega Mapa Operativo.
Es una actualización de APPS SCRIPT + GITHUB.

========================
1. MAPA OPERATIVO
========================
Se habilita el módulo Mapa Operativo según los permisos ya existentes.

CARGAS:
- CARGA INSTALACIONES
- CARGA VISITA TÉCNICA

El sistema valida el tipo de archivo para evitar cargar Instalaciones en VT o viceversa.

Los Excel se leen directamente desde la APP.
Datos principales:
OrdenId, TipoTraba, fecha solicitud, cliente, producto, cuadrilla, estado,
direcciones, código cliente/seguimiento, documento, teléfonos, FechaIniVisi,
FechaFinVisi, motivos, georreferencia, CTO 1/2/3, coordenadas CTO, CTO y puerto.

ACTUALIZACIÓN:
- La clave del Mapa es ORDEN_ID.
- Si la orden ya existe, se actualiza.
- Si la nueva descarga trae un campo vacío, se conserva el dato anterior existente.
- No se duplica el mismo OrdenId.

========================
2. CRUCE DE CUADRILLAS
========================
No se usa solamente K1/K2/etc. porque los códigos pueden repetirse entre plataformas.
Se valida por:
1. nombre completo normalizado;
2. código + plataforma;
3. código + plataforma + técnico;
4. código + técnico.
Si no existe coincidencia segura queda SIN_COINCIDENCIA para revisión.

Plataformas consideradas:
SGI / SGA / TRASLADO / POSTMOTOWIN.

========================
3. MAPA
========================
Mapa Leaflet + OpenStreetMap.
Incluye:
- marcadores por estado;
- filtros;
- cuadrilla/supervisor/plataforma/tipo visual;
- tipo de trabajo;
- estado;

- búsqueda por orden;
- detalle de cliente/dirección;
- Inicio/Fin visita;
- CTO/Puerto;

- botón Cómo llegar.

========================
4. SLA / TIEMPO DE GESTIÓN
========================
Regla:
Tiempo de gestión = FechaFinVisi - FechaIniVisi.

Se evalúan órdenes FINALIZADAS que tengan:
- Inicio y Fin de visita;
- cruce con ORDENES_DETALLE;
- ID_TARIFA/partida;
- parámetro SLA activo.

Cruce:
MAPA_ORDENES.ORDEN_ID
=
ORDENES_DETALLE.CODIGO_ORDEN_ORIGEN

Resultados:
DENTRO_SLA / FUERA_SLA / NO_EVALUABLE.

Los tiempos por partida ya fueron cargados directamente en PARAMETROS_SLA.
No es necesario volver a copiarlos.

Semáforo inicial:
- ÓPTIMO: >= 90%
- MODERADO: >= 80% y < 90%
- CRÍTICO: < 80%

Gerencia y Administrador pueden editar estos límites desde PONER INDICADORES.
