==================================================
1. VALIDACIÓN TÉCNICA
==================================================
Módulo activo desde Inicio.

TIPOS:
- RECABLEADO
- GAR
- VTR
- OTRO / NO APLICA

TICKETS:
- AT- -> RECABLEADO
- VTEXT- -> RECABLEADO
- GAR- -> GAR
- VTR- -> VTR
- NO APLICA -> OTRO

RECABLEADO
- Técnico puede registrar.
- Supervisor puede validar dentro de sus cuadrillas.
- Jefatura de Calidad, Jefatura de Operaciones y Administrador pueden validar.
- Resultado:
  APROBADO / RECHAZADO / OBSERVADO.
- Si pasan 15 minutos sin respuesta:
  SIN RESPUESTA + APROBADO AUTOMATICAMENTE.
- Para el Técnico se visualiza como APROBADO / VALIDACIÓN AUTOMÁTICA.

GAR / VTR
- Se exige ORIGEN DE ORDEN:
  PROPIA / ASIGNADA.
- Resolución:
  BONO / NO BONO.
- GAR/VTR no puede ser resuelto por Supervisor.

ALCANCE
- Técnico: su cuadrilla.
- Supervisor: cuadrillas asignadas.
- Back / Jefaturas / Gerencia / Administrador: según alcance y permisos actuales.

2. OBSERVACIONES
==================================================
Módulo activo desde Inicio.

REGISTRO
- Cuadrilla
- Fuente WIN / VISUAL
- Código
- Tipo:
  SEGURIDAD
  IMPLEMENTACIÓN
  GESTIÓN TÉCNICA
  OTRO
- Descripción
- Monto
- Código orden
- Código cliente
- Ticket

ESTADOS
- DERIVADO
- EN PROCESO
- PENALIZADO
- SUBSANADO
- APELADO
- ANULADO

DESCARGO
- Técnico ve observaciones de su cuadrilla.
- Puede registrar descargo.
- Máximo 5 evidencias.
- JPG / PNG / WEBP.
- Evidencias se guardan en Drive:
  MI VISUAL LIMA - ARCHIVOS / OBSERVACIONES - EVIDENCIAS

REVISIÓN
Los perfiles con permiso EDITAR pueden cambiar estado.
El motivo del cambio es obligatorio.
